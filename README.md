# MLCE preliminary research group website

Static website for the Machine Learning in Civil Engineering (MLCE) group at CIMNE.

## Local preview

Open `index.html` in your web browser. The stylesheet `styles.css` must remain in the same folder.

## Publish to GitHub Pages

1. Create a new public repository on GitHub, e.g. `mlce-website`.
2. Choose **Add file -> Upload files** and upload `index.html` and `styles.css` at the repository root. Commit the files.
3. Open repository **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/(root)`, then **Save**.
5. After deployment, the site URL will be `https://YOUR-USERNAME.github.io/mlce-website/` (assuming the repository is named `mlce-website`).

Edit the HTML and CSS and commit changes to publish updates.
